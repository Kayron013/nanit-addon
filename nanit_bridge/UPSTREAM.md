# Provenance

The source under `nanit-src/` derives from
[daleiii/nanit-web](https://github.com/daleiii/nanit-web) @ `88f3d37`
(MIT license), itself descended from
[indiefan/home_assistant_nanit](https://github.com/indiefan/home_assistant_nanit)
and [adam.stanek/nanit](https://github.com/adam-stanek/nanit).

This repository has since diverged and does not track upstream; the code is
maintained here as first-party source. Original MIT license attribution is
retained in the source tree.
